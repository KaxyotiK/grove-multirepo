## V2 repository and trunk behavior inventory

### `repo add`

- clones to a unique workspace staging directory outside the operation lock;
- publishes a managed bare common repository at `.bare/<repo>`;
- fixes the selected remote to `origin`, fetches remote-tracking refs, and resolves a preferred default branch;
- creates a real initial trunk worktree under `trunks/`;
- persists the initial trunk in `repositories[].trunks[]` with Grove-owned ID, branch, and directory fields;
- compensates post-publication failure by removing a created worktree and managed store.

The bare-store plus peer-worktree topology is retained. The persisted live trunk array and compensating deletion model are not.

### `repo link`

- accepts only an ordinary repository root with a `.git` directory;
- rejects a linked worktree, a subdirectory, and a bare repository;
- stores the ordinary checkout path and derives its object store as `<path>/.git`;
- creates no initial trunk and does not consult checkout HEAD as the repository default;
- nevertheless permits later `trunk add`, `trunk remove`, and `trunk sync`, warning only on add;
- permits ordinary Grove Tree creation from the shared common repository.

The no-duplicate-checkout Tree behavior is retained. Link input resolution expands to any Git-resolvable path, stores canonical common-directory identity, and all trunk mutations become pre-mutation refusals.

### Live-state ownership to remove

- `RepositoryEntry.trunks[]` persists trunk existence, branch, and directory;
- `GroveManifest.trees[]` persists Tree branch, directory, and `created|adopted` provenance;
- `claimRegistry` and claim locks treat those arrays as a branch-ownership registry;
- lifecycle rollback and repository/branch cleanup can delete Grove-classified created refs;
- read and review commands reconstruct current context from manifest records and then compare Git against the stored branch.

The redesign replaces these authorities with one bounded Git observation per invocation, central advisory metadata keyed by stable identities, conformance diagnostics, and forward operation records that never delete refs as compensation.
